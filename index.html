Panduan Membuat Google Sheets Web App

  1. Buka Google Sheets baru.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode lama, tempelkan kode Apps Script berikut: 
    function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  if (data.length <= 1) return ContentService.createTextOutput(JSON.stringify([])).setMimeType(ContentService.MimeType.JSON);
  var headers = data[0];
  var result = [];
  for (var i = 1; i < data.length; i++) {
    var obj = {};
    for (var j = 0; j < headers.length; j++) {
      obj[headers[j]] = data[i][j];
    }
    result.push(obj);
  }
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var body = JSON.parse(e.postData.contents);
  sheet.clear();
  if (!body || body.length === 0) return ContentService.createTextOutput("OK");
  var headers = Object.keys(body[0]);
  sheet.appendRow(headers);
  body.forEach(function(row) {
    var arr = headers.map(function(h) { return row[h]; });
    sheet.appendRow(arr);
  });
  return ContentService.createTextOutput("OK");
}
  4. Klik tombol Simpan (Save) (ikon disket).
  5. Klik Terapkan (Deploy) → Penerapan Baru (New deployment).
  6. Pilih jenis Aplikasi Web (Web App). Ketik deskripsi bebas.
  7. Pada Yang memiliki akses (Who has access), pilih Siapa saja (Anyone). Lalu klik Terapkan (Deploy).
  8. Salin URL Aplikasi Web (Web App URL) dan tempelkan ke kolom URL Google Sheets di portal ini.

Cara Instal Aplikasi "Brankas"

Untuk Android (Chrome) / Laptop:

  1. Klik ikon Titik Tiga (⋮) di sudut kanan atas browser.
  2. Pilih "Instal aplikasi" atau "Tambahkan ke Layar Utama".
  3. Konfirmasi pemasangan, ikon Brankas akan muncul di layar HP Anda.

Untuk iPhone / iPad (Safari):

  1. Tekan tombol Bagikan (Share) di bagian bawah browser Safari.
  2. Gulir ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen).
  3. Beri nama Brankas lalu tekan Tambah di pojok kanan atas.
